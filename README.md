# CampusOS – Student Hub Portal

CampusOS is a student hub portal developed using PHP, MySQL, HTML, CSS, and JavaScript. It provides student registration, login, dashboard access, and campus event management.

## Features

- Student registration and login
- Session-based authentication and logout
- Student dashboard and admin dashboard
- Student management
- Campus event management
- MySQL database integration
- AJAX-based event operations
- Form validation and password hashing
- Responsive user interface

## Technologies Used

- HTML, CSS, JavaScript
- PHP
- MySQL
- XAMPP and Apache
- GitHub

## Local Setup

1. Install XAMPP.
2. Copy the project folder into `C:\xampp\htdocs\campusos`.
3. Start Apache and MySQL.
4. Create the `studenthub` database in phpMyAdmin.
5. Import the provided database structure.
6. Configure the local database connection in `db.php`.
7. Open `http://campusos.local` if the virtual host is configured, or use `http://localhost/campusos/`.

## Security

- Server-side validation
- Prepared SQL statements
- Password hashing and verification
- Session-based access control
- Output escaping
- File upload validation

## Testing

Test navigation, registration, student and admin login, dashboard access, database operations, event management, and AJAX functionality.

## Purpose

CampusOS brings common student services and campus information together in one portal.
